🎙️ AI Voice Assistant: Basic Automation
A Python-based smart assistant that demonstrates the fundamentals of Speech Recognition and Natural Language Processing (NLP). This project serves as the foundation for my journey into Artificial Intelligence and Computer Science.

🚀 Overview
This project captures human voice input via a microphone, converts it to text using Google's Speech Recognition API, and performs automated tasks (like opening websites) based on specific voice commands.

🛠️ Tech Stack
Language: Python 3.x

Libraries: * SpeechRecognition: For converting audio to text.

Webbrowser: To handle automated web navigation.

PyAudio: To interface with the system microphone.

📋 Features
Ambient Noise Calibration: Automatically adjusts the microphone sensitivity based on room noise for higher accuracy.

Real-time Processing: Listens and processes speech instantly.

Command Execution: Recognizes the keyword "Google" to trigger a browser automation event.

📥 Installation & Usage!

Clone the repository:

Bash
git clone https://github.com/himanshubajpai21-coder/My-First-AI-Project.git

Bash

Run the script:
